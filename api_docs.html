HomeDesignsAI API - phần đã kiểm tra

Ngày kiểm tra: 2026-06-19. Đây là ghi chú đối chiếu cho lỗi Interior Generation, không phải bản sao đầy đủ của tài liệu nhà cung cấp.

Perfect Redesign

POST https://homedesigns.ai/api/v2/perfect_redesign

Request dùng multipart/form-data.

FieldYêu cầu / giá trịĐối chiếu app

design_typeInterior, Exterior, GardenInterior gửi Interior

Status check

GET /perfect_redesign/status_check/{queue_id}. Queue ID có hiệu lực khoảng 30 phút; tiếp tục poll qua các trạng thái queue/starting/processing cho tới SUCCESS hoặc FAILED.

Kết luận cho log đang kiểm tra

Không phải lỗi validation từ API. Lỗi xảy ra cục bộ khi app chuyển UIImage sang JPEG. CMPhotoCompressionSessionAddImage trả kCMPhotoError_UnsupportedOperation (-16994), sau đó jpegData trả nil và app tự ném Invalid image data. Vì vậy không có request /perfect_redesign nào được gửi ở lần lỗi này.

Hướng fix đề xuất

  1. Chuẩn hóa ảnh về bitmap SDR, 8-bit, sRGB trước khi encode JPEG; với UIGraphicsImageRendererFormat đặt preferredRange = .standard.
  2. Đưa logic vào một helper dùng chung cho tất cả generation flow; không gọi trực tiếp UIImage.jpegData tại từng screen.
  3. Nếu JPEG encode vẫn thất bại, fallback PNG vì API hỗ trợ PNG; không gắn MIME image/jpeg cho dữ liệu PNG.
  4. Log thêm kích thước, scale, color space/extended-range và số byte sau encode; không log ảnh/base64/token.
